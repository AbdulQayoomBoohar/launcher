# Contributing to B.A.S Bot Manager

Thanks for your interest in improving this project.

## Getting started

1. Fork the repository and clone your fork.
2. Use Python 3.8 or newer.
3. Run the bot locally first: `python basbot.py`

## Making changes

- Create a branch for your change: `git checkout -b my-change`
- Keep changes focused — one fix or feature per pull request.
- Never commit API keys, `.env` files, or session data.
- Test the launcher still starts before opening a pull request.

## Pull requests

- Describe what changed and why.
- Link any related issue.
- Screenshots or short logs help for behaviour changes.

## Reporting bugs

Open an issue with your OS, Python version, what you ran, and the full error message (with your API key removed).
